AAPA — première maquette web progressive (PWA)

CONTENU
- index.html : application de démonstration
- manifest.webmanifest : paramètres d'installation PWA
- sw.js : cache hors ligne de base

TEST RAPIDE
Ouvrir index.html dans un navigateur permet de tester l'interface, mais l'installation PWA
nécessite de publier ces fichiers sur un hébergement HTTPS.

PUBLICATION GRATUITE
1. Créer un compte sur GitHub.
2. Créer un dépôt public nommé aapa.
3. Ajouter les trois fichiers à la racine du dépôt.
4. Dans Settings > Pages, choisir Deploy from a branch, branch main, folder /(root).
5. Attendre l'adresse publiée par GitHub Pages.
6. Ouvrir cette adresse dans Chrome Android > menu ⋮ > Installer l'application
   (ou Ajouter à l'écran d'accueil).

LIMITES IMPORTANTES
Ceci est un prototype local : il n'y a pas encore de comptes sécurisés, de serveur,
de synchronisation entre élèves et enseignants, ni d'IA connectée.
Ne pas y saisir de données personnelles réelles d'élèves. La prochaine étape sera
de concevoir une base de données et des accès sécurisés avant tout essai en établissement.
